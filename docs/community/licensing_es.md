# Licencias

Comprenda el modelo de licencias de Fleetbase: AGPL-3.0 para uso de código abierto y opciones de licencia comercial para productos propietarios.

# Licencias

Fleetbase utiliza un
**modelo de doble licencia**: una licencia de código abierto para la comunidad y una licencia comercial para casos de uso propietarios.

**Texto completo de la licencia:**
[github.com/elpelaflow/PuntoShop-TMS/blob/main/LICENSE.md](https://github.com/elpelaflow/PuntoShop-TMS/blob/main/LICENSE.md)

## Licencia de Código Abierto — AGPL-3.0

La plataforma Fleetbase completa — la API principal, la Consola, las extensiones oficiales (Fleet-Ops, Ledger) y la aplicación móvil Navigator App — se distribuyen bajo la
**GNU Affero General Public License v3.0 (AGPL-3.0)**
.

### Lo que permite la AGPL-3.0

| Caso de uso | Permitido? |
|---|---|
| Alojar Fleetbase por su cuenta para sus propias operaciones | ✅ Sí, gratuito |
| Utilizar Fleetbase para operar una logística comercial | ✅ Sí, gratuito |
| Modificar Fleetbase para uso interno | ✅ Sí, gratuito |
| Crear y publicar sus propias extensiones | ✅ Sí, gratuito |
| Implementar Fleetbase como un SaaS accesible al público sin liberar cambios | ❌ Requiere licencia comercial |
| Incorporar Fleetbase en un producto de código cerrado | ❌ Requiere licencia comercial |
| Etiquetar con la marca de un producto propietario en la consola o las aplicaciones móviles | ❌ Requiere licencia comercial |

### El requisito principal

Si
**modifica**
el código fuente de Fleetbase y lo hace disponible a través de una red (por ejemplo, como un servicio SaaS que sus clientes utilizan), debe hacer que su código fuente modificado esté disponible para esos usuarios bajo la misma licencia AGPL-3.0.

Este es el requisito de copyleft central de AGPL-3.0. Garantiza que las mejoras en la plataforma se compartan de nuevo con la comunidad. Si su caso de uso implica ejecutar una instancia de Fleetbase sin modificar para sus operaciones, incluso como un servicio de pago para sus clientes, no tiene que liberar ningún código fuente.

## Licencia Comercial

Si la AGPL-3.0 no se ajusta a su caso de uso, está disponible una
**Licencia Comercial**. Esto le permite:

* Integrar Fleetbase en productos propietarios de código cerrado sin liberar sus modificaciones
* Etiquetar con la marca la Consola y las aplicaciones móviles (marca personalizada, logotipos, nombre de la aplicación) sin las obligaciones de la AGPL-3.0
* Distribuir versiones modificadas de Fleetbase de forma privada
* Recibir soporte prioritario, garantías de SLA y acceso directo al equipo principal

Las licencias comerciales están adaptadas al tamaño y al caso de uso de su organización. Para obtener información completa sobre las opciones de licencia, los niveles de precios y los términos, consulte la
[página de licencias de Fleetbase](https://fleetbase.io/licensing)
.

Para discutir una licencia comercial para su caso de uso específico, póngase en contacto con el equipo:

**[hello@fleetbase.io](mailto:hello@fleetbase.io)**

## ¿No está seguro de qué licencia le corresponde?

Si no está seguro de si su caso de uso requiere una licencia comercial, póngase en contacto con nosotros en
[hello@fleetbase.io](mailto:hello@fleetbase.io)
con una breve descripción de cómo planea utilizar Fleetbase. Le daremos una respuesta clara.

También puede preguntar en
[Discord](https://fleetbase.io/docs/community/discord)
— el canal
`#general`
es un buen lugar para preguntas sobre licencias de la comunidad.
