# Discusiones de GitHub

[Discusiones de GitHub](https://github.com/elpelaflow/PuntoShop-TMS/discussions)
es el lugar para conversaciones más largas de la comunidad sobre Fleetbase: propuestas de características, preguntas sobre la arquitectura, ideas de integración y cualquier cosa que se beneficie de un registro permanente y buscable, en lugar de un mensaje de chat en tiempo real.

**[Crear una Discusión →](https://github.com/elpelaflow/PuntoShop-TMS/discussions/new/choose)**

## Discusiones vs. Problemas vs. Discord

| Uso | Mejor lugar |
|---|---|
| Informe de error con una reproducción clara | [Problemas de GitHub](https://github.com/elpelaflow/PuntoShop-TMS/issues) |
| Pregunta sobre la instalación o el uso de la API (respuesta rápida) | [Discord `#help`](https://fleetbase.io/docs/community/discord) |
| Propuesta de característica o pregunta sobre la arquitectura | [Discusiones de GitHub](https://github.com/elpelaflow/PuntoShop-TMS/discussions) |
| Compartir algo que has creado | [Discord `#showcase`](https://fleetbase.io/docs/community/discord) |
| Cualquier cosa que deba ser buscable y permanente | [Discusiones de GitHub](https://github.com/elpelaflow/PuntoShop-TMS/discussions) |

## Categorías de Discusión

Las Discusiones de GitHub están organizadas en categorías. Elige la adecuada al abrir un hilo:

| Categoría | Cuándo usar |
|---|---|
| **Preguntas y respuestas** | Preguntas donde buscas una respuesta específica: otros pueden marcar las respuestas como respondidas |
| **Ideas** | Propuestas de características y sugerencias de mejora: buenas para la votación de la comunidad y los primeros comentarios |
| **Mostrar y Contar** | Comparte extensiones, integraciones o proyectos que hayas creado sobre Fleetbase |
| **General** | Cualquier cosa que no encaje en las otras categorías |
| **Anuncios** | Anuncios del equipo principal: solo de lectura para los miembros de la comunidad |

## Antes de Publicar

Busca discusiones existentes antes de abrir una nueva. La barra de búsqueda en la parte superior de la página de Discusiones busca tanto hilos abiertos como cerrados.

También consulta:

* [Preguntas frecuentes](https://fleetbase.io/docs/community/faq)
  para preguntas comunes
* La sección de [documentación](https://fleetbase.io/docs/platform)
  para detalles de configuración y características
* [Problemas de GitHub](https://github.com/elpelaflow/PuntoShop-TMS/issues)
  para errores conocidos

## Escribir una Buena Publicación de Discusión

**Para Preguntas y Respuestas:**

* Indica lo que estás tratando de lograr, no solo lo que está fallando
* Incluye la configuración de tu entorno (versión de Docker, entorno)
* Pega fragmentos de configuración o código relevantes utilizando bloques de código delimitados

**Para propuestas de características (Ideas):**

* Describe el problema que estás resolviendo, no solo la característica que quieres
* Explica cómo lo estás abordando actualmente
* Comparte ideas iniciales sobre la implementación si las tienes: los mantenedores estarán más dispuestos a participar si has pensado en ello

**Para Mostrar y Contar:**

* Explica brevemente qué has creado y qué problema resuelve
* Enlaza a tu repositorio o a una demostración si está disponible
