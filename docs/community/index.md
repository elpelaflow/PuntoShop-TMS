# Community & Support

Fleetbase is open-source and community-driven. Whether you need help getting started, want to report a bug, contribute code, or talk through a deployment with the core team — this is where to start.

## Real-Time Help

**[Discord Community](https://fleetbase.io/docs/community/discord)**
— the fastest way to get an answer. The
`#help`
channel is monitored by the core team and experienced community members. For installation issues, API questions, and extension development, Discord is the first stop.

**[GitHub Discussions](https://github.com/elpelaflow/PuntoShop-TMS/discussions)**
— best for longer-form questions, feature proposals, and conversations that don't have a natural end. See
[GitHub Discussions](https://fleetbase.io/docs/community/github-discussions)
for how to use it effectively.

## Bug Reports & Feature Requests

Open an issue on the relevant GitHub repository:

| Repository | What it covers |
| --- | --- |
| [fleetbase/fleetbase](https://github.com/elpelaflow/PuntoShop-TMS/issues) | Core platform, API, Console |
| [PuntoShop-TMS (Fleet-Ops)](https://github.com/elpelaflow/PuntoShop-TMS/issues) | Fleet-Ops extension |
| [PuntoShop-TMS (Ledger)](https://github.com/elpelaflow/PuntoShop-TMS/issues) | Ledger extension |
| [Navigator App](https://github.com/elpelaflow/PuntoShop-TMS/issues) | Navigator driver app |

Before opening an issue, check the
[FAQ](https://fleetbase.io/docs/community/faq)
and search existing issues — your problem may already have a solution or a pending fix.

## Contributing

Fleetbase welcomes contributions of all kinds. The
[Contributing Guide](https://fleetbase.io/docs/contributing)
has dedicated tracks for:

* **[Translations](https://fleetbase.io/docs/contributing/translations)**
  — translate the Console and extensions into your language
* **[Code](https://fleetbase.io/docs/contributing/code)**
  — submit bug fixes and features
* **[Documentation](https://fleetbase.io/docs/contributing/documentation)**
  — improve these docs
* **[Extensions](https://fleetbase.io/docs/contributing/extensions)**
  — build for the marketplace
* **[Reporting issues](https://fleetbase.io/docs/contributing/reporting-issues)**
  — file effective bug reports and feature requests

## Licensing & Commercial Use

Fleetbase is released under
**AGPL-3.0**
. Self-hosting for internal or commercial operations is free. If you need to embed Fleetbase into a proprietary product or require white-labeling without releasing your source code, a commercial license is available.

See
[Licensing](https://fleetbase.io/docs/community/licensing)
for a plain-language breakdown of what AGPL-3.0 means for your use case.
