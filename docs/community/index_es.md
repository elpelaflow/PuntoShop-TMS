# Comunidad y Soporte

Fleetbase es de código abierto y está impulsado por la comunidad. Ya sea que necesite ayuda para comenzar, desee informar sobre un error, contribuir con código o discutir una implementación con el equipo principal, aquí es donde debe comenzar.

## Ayuda en Tiempo Real

**[Comunidad de Discord](https://fleetbase.io/docs/community/discord)**
— la forma más rápida de obtener una respuesta. El canal `#help` es supervisado por el equipo principal y miembros experimentados de la comunidad. Para problemas de instalación, preguntas sobre la API y desarrollo de extensiones, Discord es el primer lugar al que acudir.

**[Discusiones de GitHub](https://github.com/elpelaflow/PuntoShop-TMS/discussions)**
— ideal para preguntas de formato largo, propuestas de funciones y conversaciones que no tienen un final natural. Consulte
[Discusiones de GitHub](https://fleetbase.io/docs/community/github-discussions)
para obtener información sobre cómo utilizarlo eficazmente.

## Informes de Errores y Solicitudes de Funcionalidades

Cree un problema en el repositorio de GitHub correspondiente:

| Repositorio | Qué cubre |
|---|---|
| [fleetbase/fleetbase](https://github.com/elpelaflow/PuntoShop-TMS/issues) | Plataforma principal, API, Consola |
| [PuntoShop-TMS (Fleet-Ops)](https://github.com/elpelaflow/PuntoShop-TMS/issues) | Extensión Fleet-Ops |
| [PuntoShop-TMS (Ledger)](https://github.com/elpelaflow/PuntoShop-TMS/issues) | Extensión Ledger |
| [Navigator App](https://github.com/elpelaflow/PuntoShop-TMS/issues) | Aplicación Navigator Driver |

Antes de crear un problema, consulte la
[Preguntas frecuentes](https://fleetbase.io/docs/community/faq)
y busque problemas existentes — es posible que su problema ya tenga una solución o una corrección pendiente.

## Contribuir

Fleetbase da la bienvenida a contribuciones de todo tipo. La
[Guía de contribución](https://fleetbase.io/docs/contributing)
tiene carriles dedicados para:

* **[Traducciones](https://fleetbase.io/docs/contributing/translations)**
  — traduzca la Consola y las extensiones a su idioma
* **[Código](https://fleetbase.io/docs/contributing/code)**
  — envíe correcciones de errores y funciones
* **[Documentación](https://fleetbase.io/docs/contributing/documentation)**
  — mejore estos documentos
* **[Extensiones](https://fleetbase.io/docs/contributing/extensions)**
  — cree para el mercado
* **[Informar sobre problemas](https://fleetbase.io/docs/contributing/reporting-issues)**
  — cree informes de errores y solicitudes de funciones eficaces

## Licencia y Uso Comercial

Fleetbase se publica bajo
**AGPL-3.0**
. La auto-hospedaje para operaciones internas o comerciales es gratuito. Si necesita integrar Fleetbase en un producto propietario o requiere etiquetado sin publicar su código fuente, está disponible una licencia comercial.

Consulte
[Licencia](https://fleetbase.io/docs/community/licensing)
para obtener una explicación en lenguaje sencillo de lo que significa AGPL-3.0 para su caso de uso.
