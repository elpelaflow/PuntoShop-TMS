# Documentación de Fleetbase

— Una plataforma lista para su uso que los operadores y desarrolladores pueden implementar en su propia infraestructura, ampliarla con lógica personalizada y poseerla por completo. Sin dependencia de un proveedor. Sin precios por usuario. Sin "cajas negras".

## Módulos de la Plataforma

PuntoShop TMS incluye un conjunto de módulos dedicados exclusivamente a la gestión de transporte y operaciones logísticas.

| Módulo | ¿Qué hace? |
|---|---|
| **[Fleet-Ops](https://fleetbase.io/docs/fleet-ops)** | Gestión de flotas, asignación y despacho de viajes, seguimiento en tiempo real de conductores, telemática y optimización de rutas. El motor TMS principal para operaciones de transporte. |
| **[Ledger](https://fleetbase.io/docs/ledger)** | Contabilidad y facturación de fletes. Genera facturas a partir de viajes, procesa cobros y realiza un seguimiento financiero de la operación. |
| **[Developer Console](https://fleetbase.io/docs/platform/developer-console/api-keys)** | Gestión de claves de API, configuración de webhooks, supervisión de eventos de socket y registros de solicitudes para integraciones externas. |

## ¿Qué cubre la documentación de la plataforma?

Esta sección de la **Plataforma** cubre el sistema base que subyace a todos los módulos:

* **Comenzar**
  — Arquitectura, opciones de implementación y orientación
* **Inicio rápido**
  — Comienza a utilizarlo en la nube o localmente en minutos
* **Configuración del sistema**
  — Configura el correo electrónico, el almacenamiento, las colas, los sockets y la marca
* **Identidad y acceso**
  — Usuarios, roles, permisos, políticas y organizaciones
* **Consola de desarrollador**
  — Claves de API, webhooks, eventos de socket y registros de solicitudes
* **Características de la consola**
  — Navegación, paneles, campos personalizados, internacionalización y notificaciones

Para la documentación específica de un módulo, utiliza la navegación para cambiar entre Fleet-Ops, Ledger, CLI, UI Library, Extension Development y API Reference.
