## Platform Modules

PuntoShop TMS ships with a focused set of modules dedicated exclusively to transport management and logistics operations.

| Module | What it does |
| --- | --- |
| **[Fleet-Ops](https://fleetbase.io/docs/fleet-ops)** | Fleet management, order dispatch, real-time driver tracking, telematics, and route optimisation. The core TMS engine for transportation logistics. |
| **[Ledger](https://fleetbase.io/docs/ledger)** | Freight accounting and invoicing. Generate invoices from transport orders, process freight payments, and track operational financials. |
| **[Developer Console](https://fleetbase.io/docs/platform/developer-console/api-keys)** | API key management, webhook configuration, socket event monitoring, and request log viewing for external integrations. |
