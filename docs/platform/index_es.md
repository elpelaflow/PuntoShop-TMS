# Plataforma Central

La plataforma central de Fleetbase abarca la gestión de identidades, las herramientas para desarrolladores, extensiones y las características integradas de la plataforma.

# Plataforma Central

La plataforma central de Fleetbase es la base sobre la que se construyen todos los módulos y extensiones. Gestiona las necesidades que requiere cualquier sistema de logística serio: gestión de organizaciones multi-inquilino, control de acceso basado en roles, un bus de eventos en tiempo real, una API REST y una consola para desarrolladores para gestionar las integraciones.

Comience con la
[Visión general de la plataforma](https://fleetbase.io/docs/platform/getting-started/overview)
para una introducción completa, o vaya directamente a la guía rápida si ya sabe qué necesita.
